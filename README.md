# LOOKLIE Генератор

Панель для детских AI-видео (YouTube Shorts) с постоянным персонажем — мальчиком LOOKLIE.

- Модель: Grok Imagine 1.5 Lite (Higgsfield), 9:16, 720p, 10 секунд, английский язык, без референса.
- `index.html` — сайт (GitHub Pages): одобрение и правка сценариев, сборка промптов.
- `scenarios.json` — список сценариев (`proposed` / `done`).
- `CHARACTER.md` — описание персонажа и шаблон промпта.
- `character/looklie-boy.png` — референс-картинка персонажа.

Генерацию выполняет Claude: на сайте нажмите «Скопировать команду» и вставьте её в чат. Готовые видео сохраняются в папку «YouTuBe UP!» на рабочем столе (в репозиторий не попадают).

## Автогенерация

Помощник `server.js` работает у вас на компьютере; сайт отправляет ему одобренные сценарии, он делает видео по очереди и кладёт в «YouTuBe UP!».

**Режим CLI (по умолчанию):** помощник запускает `claude -p`, тот вызывает ваш Higgsfield MCP (модель Grok Imagine 1.5 Lite). Ключ API не нужен.
1. Один раз выполните в терминале `claude login` и убедитесь, что Higgsfield MCP подключён в вашем аккаунте.
2. Запустите `start-server.bat` (нужен Node.js), окно не закрывайте.
3. На сайте индикатор вверху станет зелёным: «Одобрить» → «Сгенерировать видео».

**Режим API:** в `.env` укажите `MODE=api` и `HF_KEY=ID:SECRET` (ключ из console.higgsfield.ai). Файл `.env` в репозиторий не попадает.


## Как идёт генерация (актуально)
Помощник (`start-server.bat`) по умолчанию работает в режиме **hf**: вызывает Higgsfield CLI `hf.exe` (модель `grok_video_v15_lite`, 9:16, 720p, 10 сек), как в проекте «Автоматизация Контента». Вход в Claude и API-ключ не нужны. Режимы `cli` и `api` остались как запасные.
