# LOOKLIE Генератор

Панель для детских AI-видео (YouTube Shorts) с постоянным персонажем — мальчиком LOOKLIE.

- Модель: Grok Imagine 1.5 Lite (Higgsfield), 9:16, 720p, 10 секунд, английский язык, без референса.
- `index.html` — сайт (GitHub Pages): одобрение и правка сценариев, сборка промптов.
- `scenarios.json` — список сценариев (`proposed` / `done`).
- `CHARACTER.md` — описание персонажа и шаблон промпта.
- `character/looklie-boy.png` — референс-картинка персонажа.

Генерацию выполняет Claude: на сайте нажмите «Скопировать команду» и вставьте её в чат. Готовые видео сохраняются в папку «YouTuBe UP!» на рабочем столе (в репозиторий не попадают).
